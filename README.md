# Timeline — ДЗ «10. Geolocation, Notification, Media»

Лента постов (Timeline) с привязкой к геопозиции: текстовые записи, аудио- и видеозаписи.
Проект курса «Продвинутый JavaScript» (Нетология).

**GitHub Pages:** https://jusnd.github.io/ahj-media/

## Функциональность

### Задача 1. Текстовые записи с координатами
- Текст вводится в поле внизу, по нажатию Enter запрашиваются координаты через Geolocation API.
- Если геолокация доступна — запись добавляется в ленту вместе с координатами.
- Если геолокация недоступна — открывается модальное окно с предложением ввести координаты вручную.
- Ручной ввод валидируется функцией `parseCoordinates` (`src/js/parseCoordinates.js`):
  - `51.50851, −0.12572` (с пробелом);
  - `51.50851,−0.12572` (без пробела);
  - `[51.50851, −0.12572]` (в квадратных скобках);
  - типографский минус `−` (U+2212) корректно обрабатывается.
- При неверном формате функция генерирует исключение — поле подсвечивается красным (валидация), показывается текст ошибки.
- На функцию написаны авто-тесты (Jest): `src/js/__tests__/parseCoordinates.test.js`.

### Задача 2*. Аудио-записи с координатами
- По нажатию на иконку микрофона начинается запись аудио (MediaRecorder API).
- Во время записи иконки микрофона и камеры заменяются на «ОК» (галочка), «Отмена» (крестик) и таймер с длительностью записи.
- По «ОК» запись завершается, определяются координаты (либо предлагается ввести вручную), запись добавляется в ленту как `<audio controls>` и доступна для прослушивания.
- Если API недоступно или пользователь не выдал права — показывается всплывающее уведомление.
- При записи звук не дублируется.

### Задача 3*. Видео-записи с координатами
- По нажатию на иконку камеры начинается запись видео.
- Появляется всплывающий блок с превью — дублируется **только изображение** (атрибут `muted`, звука нет).
- По «ОК» запись завершается, запрашиваются координаты, запись добавляется в ленту как `<video controls>` и доступна для проигрывания.

Данные хранятся в памяти (без серверной части), как указано в задании.

## Технологии

- Webpack 5 (сборка JS и CSS, Babel)
- Jest — авто-тесты
- GitHub Actions — автоматическая сборка и деплой на GitHub Pages (`.github/workflows/deploy.yml`)

## Как запустить локально

Требования: **Node.js 18+** и npm.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/jusnd/ahj-media.git
cd ahj-media

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер (http://localhost:8080)
npm run dev
```

Другие команды:

```bash
npm test        # запустить авто-тесты
npm run build   # собрать продакшн-версию в папку dist/
```

> **Важно:** Geolocation API и MediaRecorder работают только в безопасном контексте —
> `https://` или `http://localhost`. Поэтому локально открывайте именно `http://localhost:8080`,
> а в интернете — страницу GitHub Pages (https). Браузер запросит разрешение на доступ
> к геолокации, микрофону и камере — их нужно разрешить.
